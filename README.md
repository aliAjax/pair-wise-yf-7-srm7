# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 草稿核量与缺字待补

- 每次落字都会记下所用字模（字、风格、字号、磨损）的快照；草稿与当前字模库**持续对账**。
- 某款字模被清走或库存枚数不足时，草稿卡片会写明作品名、缺少枚数与对应字模（含「已清走 / 不足」原因）。
- 载入草稿后，缺字格保留原字并以红色虚线标为**待补**；重新补进同字同风格的字模时会按阅读顺序自动归补。
- 也可选中一款现有字模，点击待补格直接换用；角标、草稿卡片与导出条件随即更新。
- 仍有缺口时点击「导出预览图」不会生成 PNG，页面下方会列出缺哪款字模、少几枚。
