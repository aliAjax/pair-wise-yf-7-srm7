# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、保存草稿并导出 PNG 预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 草稿与字模库核量

- 落字时会记下字模的字、风格、字号、磨损；字模事后被撤走，草稿和版面上的格子仍保留原字，并以红框和「待补」角标标出。
- 草稿卡片每次打开都会对照当前字模库核量，写明作品名、缺少枚数和对应字模：
  - **库中已清走**：该款字模不在库里，列出缺几枚；
  - **库存不足**：用了几枚、库存几枚、还差几枚。
- 补回同字同风格的字模（或点字模卡上的「＋」增补枚数）后，草稿会自动重新接回并复核，提示随即更新；库中有同字不同款字模时，可在草稿卡片上一键「换用现有字模」。
- 仍有缺口时点「导出预览图」不会出图，页面会说明缺哪款字模、少几枚，避免生成漏字预览；缺口补齐或换用后导出按钮恢复可用。
